# APIMatic Context Plugin log

This log records each lookup made with the APIMatic Context Plugin (ContextMatic) MCP server while writing PayPal Server SDK (`@paypal/paypal-server-sdk@2.5.0`) code, and the code each answer informed. The plugin is used at coding time only; the app never calls it at runtime.

## How the server was reached

- Endpoint: `https://chatbotapi.apimatic.io/mcp/plugins` (MCP JSON-RPC over streamable HTTP, server name `ContextMatic` 1.0.0).
- An unauthenticated `initialize` returns `401` with `WWW-Authenticate: Bearer resource_metadata=...`. The authorization server (`https://chatbotapi.apimatic.io`) supports dynamic client registration and the `client_credentials` grant with no user credentials:
  1. `POST /register` with `token_endpoint_auth_method: "none"` returns a public `client_id`.
  2. `POST /token` with `grant_type=client_credentials`, that `client_id`, `scope=mcp:tools` and `resource=https://chatbotapi.apimatic.io/mcp/plugins` returns a bearer token.
  3. `initialize` with the bearer token returns an `Mcp-Session-Id`; then `notifications/initialized`, `tools/list` and `tools/call`.
- Tools listed: `fetch_api`, `ask`, `endpoint_search`, `model_search`, `update_activity`.
